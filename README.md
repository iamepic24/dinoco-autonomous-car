# Dinoco – UAMC 2026

**Team Dinoco · TM-181B7D2C3C6**

Source code for our autonomous RC car, built for the **Urban Autonomous Mobility Challenge (UAMC)** at **Techfest, IIT Bombay**.

- Platform: Raspberry Pi 5 + ESP32
- Sensors: camera + RPLIDAR C1
- Round 1: lane-keeping, obstacle stop, STOP sign, E-stop
